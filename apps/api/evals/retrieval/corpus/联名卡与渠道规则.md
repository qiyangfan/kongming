# 联名卡编号

联名会员卡按发卡渠道分为三类:官方直营渠道卡号前缀 LY-2024-A,合作书店渠道前缀 LY-2024-B,线上渠道前缀 LY-2024-C;三类卡在门店租借时分别享 9 折、88 折与 85 折优惠,折扣仅作用于租金,不含逾期费。

# 渠道权益差异

LY-2024-A 卡可参加每月会员日活动;LY-2024-B 卡可在合作书店积分互通;LY-2024-C 卡仅支持线上预约到店取片,不支持现场直接租借。联名卡不参与团体租借优惠叠加。

# 开卡与注销

联名卡开卡免工本费,注销须结清全部欠费;卡号注销后 90 天内不得以同一手机号重新开卡。渠道合作终止时,对应前缀卡号自动降级为普通会员卡,剩余折扣权益在当月结算后失效。
