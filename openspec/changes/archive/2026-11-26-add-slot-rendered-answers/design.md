# Design: add-slot-rendered-answers

## 问题定性

现机制是「对开放输入做封闭枚举」:自由文本里任何数字样片段都要与集合比对,而租户的
标签、日期、编码形态无界,集合补不完;且补救手段是句级删除,单句回答会被删空,
再回落为对结果集的统计罗列。反过渡方案是把约束放到输出文法:模型只能经系统给定的
槽位引用数字,系统是数字的唯一作者;判定从「值属于哪个集合」变为「文法是否合规」,
与租户词汇无关。

## 决策 1:槽位语法与命名空间

语法:`{{命名空间.键}}`,单层花括号成对,键内不嵌套。留存的裸 `{`/`}` 一律畸形。

命名空间(按本轮形态下发,未出现的键不提供):

| 槽位 | 含义 |
| --- | --- |
| `{{rows}}` | 结果行数(结构性常量) |
| `{{stats.<列>_max\|_min\|_avg}}` | 既有 stats 键 |
| `{{argmax.<列>.label}}` / `.value` | 该列最大值所在行的标识列文本 / 最大值;`argmin` 同构 |
| `{{cell.<r>.<c>}}` | 结果单元格(0 起,越界即违约);datetime 渲染日期部分,NULL 渲染「空」 |
| `{{q.<i>}}` | 问句(已改写)中第 i 个数值 token,规范化渲染(前提数字) |
| `{{calc.<键>}}` | 计算工具返回值(delta_pct/share_pct/share,百分比按 % 渲染) |
| `{{alias.<i>}}` / `{{alias.<i>.physical}}` | 召回表段的业务称谓 / 物理表名 |
| `{{nulls.<列>}}` | 该列空值计数(数据质量类洞察用,内部派生) |

- argmax/argmin 由 compute_stats 旁路派生:沿用既有度量资格判定(`_is_stat_worthy`),
  标签取极值行首个文本列;无文本列则只提供 `.value`。**只作槽位与提示词上下文,
  不写入对外 stats 字段**(前端徽标口径不变)。
- `cell` 引用允许超出前 5 行预览(渲染对全量结果行,值真实性由系统保证);归因
  正确性(谁最大/最小)由 argmax/argmin 槽位承担,与既有审计的边界一致。
- 问句前提数字复用 `numeric.extract_numbers`,以 `q.i` 入槽位,不再进白名单。

## 决策 2:契约校验与渲染顺序

1. 剥离引用键标记(【…】,含十六进制后缀,属系统既有文法);
2. 剥离全部槽位 token;
3. 违规扫描:残留 `[0-9０-９]` 即字面数字违约;残留花括号即语法畸形违约;
4. 槽位解析:键必须在清单内、cell 行列在界内,否则未知槽位违约;
5. 全部通过才替换渲染;任一步失败整段弃用(不做句级删除,避免悬空指代),
   进入兜底分层。

禁扫描数字前不剥引用键会误伤 `【员工手册-A7F2】` 这类合法标记,顺序固定。

## 决策 3:标量结果确定性作答

条件:PASS 且 1 行 1 列数值(非 bool)。模板:

- 计数类(投影为 COUNT 或列名含 count)且问句可识别量词(固定词表:条/个/笔/次/
  家/人/台/件/部/元/美元):「共 {值}{量词}」;
- 其余聚合:「{称谓}为 {值}{量词}」,称谓取指标命中别名或缺省列名;
- 称谓与量词皆不可得:「结果为 {值}」。

不调用模型,insights 为空(stats 徽标照常展示)。这是「契约确定的答案不交给模型
复述」的落点,同时省一次模型调用。

## 决策 4:兜底分层

| 层级 | 触发 | 输出 |
| --- | --- | --- |
| T0 标量作答 | 1×1 数值 | 决策 3 模板 |
| T1 槽位渲染 | 契约校验通过 | 模型文本经槽位替换 |
| T2 确定性轮廓 | 多行结果的违约/渲染失败 | 「共 N 行;{标签} 最高为 X…」+「未生成解读」 |
| T3 融合退化 | 融合正文违约 | 复用既有纯数据答退化路径(来源为空) |

T2 不使用 max/min/avg 三元罗列,不取未渲染的自由文本。trace 事件
`answer_contract` 记录 `{violation, slot, tier}`(violation 枚举:literal_digit /
malformed / unknown_slot / render_error / doc_number_unquoted),经既有 trace 通道
进入 stage_trace 与事件流。

## 决策 5:融合问答的文档数字

数据结论数字走槽位;文档引用的数字允许字面量,但逐个 token 须为下发文档 parts 的
逐字片段(去空白归一后子串匹配)。不通过则整段弃用,走 T3,`_note_fused_fallback`
原因记 `doc_number_unquoted`。校验的是「是否引用原文」而非数值集合;任意租户文档
自洽,无 per-tenant 规则。引用键净化与来源投影原样复用。

## 决策 6:退役清单

- 删除 `numeric.audit_text / filter_insights / audit_summarize_output`、
  `nodes.fallback_summary` 及三条路径的调用与对应测试;
- 保留 `numeric.extract_numbers / normalize_number / value_in_whitelist /
  build_whitelist / compute_delta / compute_share / precompute_derived_stats`:
  前两者服务槽位与文档校验,后几者服务计算工具的结构化入参校验(与自由文本比对
  不是同一机制);
- 三处提示词改写,`test_prompts` 断言同步;prompt 指纹变化,评测重跑。

## 考虑过的替代

- **前提数字补白名单**:只覆盖「复述问句」一类,含数字标签与日期仍误删,开放集合
  补不完,否决。
- **剥离后受控重写一次(模型重试)**:违背既有「审计不重试」时延口径,且重写仍
  需审计,失败面不变,否决。
- **完全模板化(模型不写数字也不写模板句)**:标量场景已采纳(T0);多行结果保留
  自然语言的分析价值,槽位已保证数字真实,全面模板化收益低、表达损失大,不采纳。
- **数字占位符由前端渲染**:数字需与结果表/图表同源展示,前端改动面大且无额外
  正确性收益,不采纳。

## 风险

- 模型违约率:探针 2/2 合规;违约可观测且落 T2,不阻断结果面;apply 阶段以评测
  tier 分布复核,必要时只调提示词示例,不放开数字禁令。
- 槽位清单使提示词变长:只按本轮结果形态暴露必要键,受既有装配上界校验约束。
- T2 句式生硬:首版接受;后续只调模板,不放宽契约。

## 边界

- 中文数字不在禁令内(登记,与现审计的既有缺口一致)。
- cell 槽位可引用未见行(仅位置性引用);值真实性由系统保证,语义归因靠
  argmax/argmin 与评测,不承诺更强。
- 报告生成链路不在本契约内。
