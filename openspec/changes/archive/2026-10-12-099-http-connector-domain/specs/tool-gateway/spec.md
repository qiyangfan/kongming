# Spec Delta

## ADDED Requirements

### Requirement: HTTP 连接器注册与凭证治理

系统 SHALL 支持租户级注册自定义 HTTP 端点为 Agent 工具:注册声明含工具名称、
描述、HTTP 方法(GET/POST 白名单)、路径模板(支持占位参数)、输入参数声明
(名/类型/必填/描述的有限集合)、出口主机白名单、鉴权形态(none/bearer/
api-key 头/basic)与鉴权材料。鉴权材料 SHALL 加密落库(与既有 webhook 密钥
同一加密机制),任何接口 MUST NOT 回显明文——列表与详情只呈现形态与尾号掩码,
创建/更新响应亦不回显。注册校验 SHALL fail-fast:路径模板占位与参数声明
不求交、白名单为空或含非法主机、方法越白名单 MUST 保存期拒绝。连接器 MUST
严格租户内(跨租户 404 同形);管理操作(增删改/启停)SHALL 要求连接器管理
权限点;删除为硬删并落操作审计。同租户内连接器 key MUST 唯一。

#### Scenario: 注册连接器进入注入集

- **GIVEN** 持连接器管理权限的租户用户注册了合法 HTTP 连接器(启用态)
- **WHEN** 持工具调用权限的用户发起 ReAct 问答
- **THEN** 该连接器工具出现在注入集,Agent 可经既有工具回调调用它

#### Scenario: 凭证不回显

- **GIVEN** 注册时填入 bearer 令牌
- **WHEN** 查询连接器列表与详情(含创建/更新响应)
- **THEN** 任何响应只含鉴权形态与尾号掩码,不含令牌明文

#### Scenario: 注册校验 fail-fast

- **GIVEN** 注册声明路径含占位 `{order_id}` 但参数声明未含该参数,
  或白名单为空
- **WHEN** 提交注册
- **THEN** 保存期拒绝并附可读原因,不落库

#### Scenario: 跨租户不可见

- **GIVEN** 租户 A 注册的连接器
- **WHEN** 租户 B 用户查询列表或直访该连接器
- **THEN** 列表不含该项,直访 404 同形

### Requirement: HTTP 连接器出站安全

连接器执行 SHALL 经域策略器强制出口校验:实际出站 URL 的主机 MUST 精确命中
该连接器声明的白名单(端口与 scheme 一并受路径模板约束,MUST NOT 允许重定向
到白名单外主机——重定向跟随默认关闭),未命中拒绝并落审计。出站目标 SHALL
先经既有 SSRF 拒绝段判定(回环/私网/链路本地/云元数据地址一律拒),判定
拒绝优先于白名单命中。参数校验按注册参数声明执行(越界/缺必填/类型不符
拒绝,结构化错误观察喂回 LLM)。连接级失败 SHALL 重试至多一次,响应类错误
(4xx/5xx/超时读)MUST NOT 重试。超时按注册声明(部署级上限封顶)。

#### Scenario: 白名单外主机拒绝

- **GIVEN** 连接器白名单仅含 api.example.com
- **WHEN** LLM 试图调用路径模板拼出 evil.example.com 的请求
- **THEN** 策略器出口校验拒绝,不出站,返回结构化拒绝观察并落审计

#### Scenario: SSRF 拒绝优先

- **GIVEN** 某连接器白名单被注册为含内网地址形态(注册期 SSRF 判定拦截;
  存量行以执行期判定兜底)
- **WHEN** 执行期出站目标命中 SSRF 拒绝段(如 169.254.169.254)
- **THEN** 不出站,按策略拒绝落审计(白名单命中不构成豁免)

#### Scenario: 响应类错误不重试

- **GIVEN** 连接器端点返回 500
- **WHEN** 出站执行
- **THEN** 仅调用一次,失败分类为响应类,降级为结构化错误观察

#### Scenario: 重定向不出白名单

- **GIVEN** 白名单内端点 302 重定向到白名单外主机
- **WHEN** 出站执行
- **THEN** 不跟随重定向,按响应类失败收口(不静默跟随)

### Requirement: HTTP 连接器注入授权与写确认

连接器工具权限点 SHALL 为显式授予制(不进默认角色推荐集,SUPER_ADMIN 种子
自动覆盖);注入集 SHALL 按请求按租户维度动态装配——已启用连接器经注册
闸门(名称/描述过输入护栏)后对授权用户可见,注册/编辑/启停 SHALL 即时
生效(下一请求可见,MUST NOT 要求进程重启)。非 GET 方法连接器缺省标记
「需确认」,执行前 SHALL 走既有写工具确认流;注册可显式声明读语义豁免
(仅限 GET)。执行 MUST 以发起用户身份经既有防御层,凭证仅由控制面出站
通道装配(ADR-002 不动);连接器执行配额 SHALL 并入既有工具域配额分桶
(域=http 连接器,独立于其它域)。

#### Scenario: 启停即时生效

- **GIVEN** 某连接器已在注入集
- **WHEN** 租户管理员停用它
- **THEN** 下一请求注入集不再含该工具,直调回调被拒并落审计(无需重启)

#### Scenario: 写语义缺省需确认

- **GIVEN** 注册了一个 POST 连接器未显式声明读语义
- **WHEN** LLM 调用该工具
- **THEN** 执行前进入既有写工具确认流,用户确认后才出站

#### Scenario: 未授权用户不可见

- **GIVEN** 用户未获连接器调用权限点
- **WHEN** 发起问答
- **THEN** 连接器工具不出现在注入集,直调回调被拒并落审计

### Requirement: HTTP 连接器执行观察与审计

响应体 SHALL 经整形进工具观察:JSON 响应序列化为文本形态并有大小上限
(超限截断并标注截断),响应头不进观察;外部响应内容按外部数据处理
(进入观察前经既有注入检测面)。执行(成功/拒绝/失败/限流/超时)SHALL 落
既有工具审计表(域标签=http 连接器,记录连接器标识、参数摘要、成败分类
与耗时),与既有域同表同语义;失败分类至少区分 unreachable/protocol/policy,
降级为结构化错误观察,MUST NOT 暴露内部堆栈、端点内网细节与鉴权材料。
非 LLM 调用 MUST NOT 落 LLM 用量记录。

#### Scenario: 大响应截断标注

- **GIVEN** 端点返回超大 JSON 响应
- **WHEN** 执行完成
- **THEN** 观察含截断后的文本形态与截断标注,不超观察大小上限

#### Scenario: 执行留痕同表

- **GIVEN** 连接器执行一次(无论成败)
- **WHEN** 查询工具审计
- **THEN** 既有审计表新增一行且带域标签与连接器标识,无 LLM 用量新行

#### Scenario: 错误观察不含敏感细节

- **GIVEN** 端点连接失败
- **WHEN** 降级观察组装
- **THEN** 观察只含失败分类与友好文案,不含堆栈、内网地址与鉴权材料

### Requirement: 既有域零回归

HTTP 连接器域接入 MUST NOT 改变既有域(websearch/knowledge)与内置工具的
任何行为:注入、授权、执行路径、审计形态逐字段一致;未注册连接器的租户
MUST 与「能力从未存在」不可区分。

#### Scenario: 既有域行为一致

- **GIVEN** 任意既有域工具的任一场景
- **WHEN** HTTP 连接器域引入后执行
- **THEN** 行为与引入前逐字段一致(含 websearch 全部场景回归)
