# Tasks

## 1. 固定题集和判定条件

- [x] 1.1 建立独立于 Wiki 整理的正式题集，覆盖单资料、多段综合、跨资料、原文冲突和无答案情形；为每题固定标准事实与必需原文，并用题集自检测试验证字段、类别和题量下限。
- [x] 1.2 在评测配置中固定模型、提示词版本、向量化通道、作答上限、题型门槛、引用要求及费用和维护时间上限；增加配置测试，确保缺少必要条件时评测不能给出接入建议。

## 2. 整理并核对 Wiki 页面

- [x] 2.1 编写评测专用的页面生成程序，记录原文清单、模型和提示词版本；增加测试，确认每条页面事实都能按文档名和片段定位到所在父块，且父块摘要与页面记录一致。
- [x] 2.2 保存经人工核对的主题页及核对记录；用页面校验测试拒绝缺少出处、原文不匹配或未审核的页面。

## 3. 核对原文和访问权限

- [x] 3.1 先编写资料删除、同名覆盖更新（资料编号重建）、内容更新、租户不符、数据源不符和账号失去访问权限的失败用例，再实现运行前资料核对；相关用例通过且无效页面不会进入回答模型。
- [x] 3.2 增加运行期间资料变更检查；通过模拟资料变化的测试确认本次结果作废，并在评测说明中写明隔离环境和资料清理方法。

## 4. 执行三种取材方式

- [x] 4.1 实现原文检索、Wiki 优先和并行取材三种评测方式；Wiki 页与查询向量化统一走 Agent 内部向量化接口，并固定共用的模型、提示词和作答预算；用模拟 API 响应的测试核对每题调用次数和输入证据。
- [x] 4.2 实现 Wiki 无有效页面时转用原文检索，以及并行方式单路失败时的处理；用测试验证转用原因、来源去重和总时限。

## 5. 评分并生成报告

- [x] 5.1 实现去掉方式标签、打乱顺序的逐题评审对象，接入版本化评分规则的评审模型，并提供评审者分层抽样校准与存疑项复核的记录；用评分测试验证答案正确、证据齐全和引用支持分别统计。
- [x] 5.2 补齐评测对话客户端的用量采集，生成按题型比较的结果、差异范围、转用比例、延迟、可核实模型费用和人工整理时间；为统计与接入判定规则增加测试，并更新评测使用说明。

## 6. 完成隔离评测

- [x] 6.1 在隔离评测环境运行正式题集，保存逐题结果和汇总报告；确认无越权或失效来源进入回答，并按预先登记的条件给出 Wiki 优先、并行取材、维持原文检索或证据不足的唯一结论。
- [x] 6.2 运行本变更的 OpenSpec 严格校验和相关评测门禁；所有结果写入报告，未通过项及其影响明确记录。

## Workflow follow-up

- 评测通过后，另立生产接入提案，明确正式问答行为、资料更新与访问权限处理、发布步骤和回退方式。
- 评测未通过或资料不足时，保留原文检索方案；只有补齐证据并重新评测后再考虑生产接入。
