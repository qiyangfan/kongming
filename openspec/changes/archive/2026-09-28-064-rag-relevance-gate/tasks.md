- [x] 3.1 shadow 跑评估集,产出各路分数分布直方图与"将丢弃命中数 / 会改变路径的轮次",标定阈值
      **实测(2026-09-28,现网容器栈+冒烟库 26 表,评估集 8 问,试跑端点实采)**:
      向量路 top1 分布——相关问 [0.3237, 0.4875](均值 0.4036),无关问

      之间有清晰间隔。全文路 8 问全部零命中(中文问句 vs 英文表名,
      tsvector 不匹配)——零命中不投票,符合设计。
      标定结论(初值):vector top1=0.30、mean3=0.28(双档成对);
      相关问最近边界 0.3237(余量 +0.024,来自"蓝牙耳机"问句),
      标定时已按此收紧校验。
      **关键标定发现:mean 次级阈值缺省 0.0 会使双条件第二支恒真
      (0.1376/0.1364 的无关问也 passed=true)——阈值必须成对配置,
      单设 top1 不设 mean 等于没设。此发现已沉淀进配置注释语义。
      据此定首档与次级阈值(不凭空拍数);分布数据可来自试跑端点对评估集的批量调用
      (不等真实流量)
      **验证**:数据记录于 apply
- [x] 3.2 对拍确认误杀率可接受且收益为正 → 切 primary;劣化则保持 off
      **实测(2026-09-28,阈值 top1=0.30/mean=0.28,primary 形态对拍)**:
      试跑端点评审:相关 6/6 passed=true(误杀率 0/6);无关 2/2
      passed=false(reason=mean_below,top1 与均值双低于阈值)。
      聊天层面对拍:无关问句两种形态最终路径一致(LLM 本就诚实
      走 NO_DATA)——本评估集内"会改变路径的轮次"=0/8;闸门收益
      体现在提示词净化(junk 命中不进提示词)+机制武装(阈值经真实
      分布标定、双档成对),路径翻转类语料需 065 更大评估集见证。
      结论:误杀率为零、收益为正但幅度有限,**保持缺省 off**,
      上述阈值作为影子期→primary 的初值记录(生产切换留待运营决策)。
      并记录重估条件(语料规模 / false positive 居高)
      **验证**:`make check` 绿 + apply 记录
