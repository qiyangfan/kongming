# Design: 运行时策略执行（runtime-policy）

## Context

现有 kongming 本地护栏规则/审计；锦官将拥有共享策略包激活。规则体/规则类型是服务域配置。

## Goals / Non-Goals

**Goals:**
- 共享策略包执行本地化。
- 规则体/规则类型仍可本地管理；锦官只读展示。

**Non-Goals:**
- 不拥有共享策略包激活/作用域。
- 不做通用策略 DSL。
- 不改执行引擎。

## Decisions

1. 共享策略包快照本地缓存；缺失/非法安全类 fail-closed。
2. 本地保留规则目录/规则体编辑与审计；共享激活只读。
3. 共享策略包激活/回滚由锦官；本地规则变更由服务 admin API 落库。
4. 运行时控制台分离共享激活（只读）与本地规则（可写）。

## Risks / Trade-offs

- 策略包快照陈旧 → stale 提示/安全类拒绝。
- 包引用与本地规则目录漂移 → 契约测试/能力目录。
- 执行不一致 → 规则版本/契约测试。

## Migration Plan

greenfield：删除本地共享策略激活；保留本地规则目录；从快照加载。
