# Design

## Context

`SqlDocumentRepo.recall_children_fulltext` 先查所有词都匹配的子段落，没有结果时再查命中任一内容词的子段落。两轮都用 `ts_rank` 排序。文档检索将关键词名次与向量名次用 RRF 合并，再取回原文段落。`GET /system/document/retrieval-probe` 与问答调用同一套检索和合并逻辑。

## Goals / Non-Goals

- 在真实的检索流程中，只替换关键词排序，测出它对证据覆盖率和检索耗时的影响。
- 语义模型、中文分词、候选筛选、结果合并和作答质量属于其他评测变量。

## Decisions

### 复用现有试跑接口

沿用 `apps/api/evals/retrieval/` 的进程外评测。隔离评测环境中，基线组使用原 API，实验组由评测启动器在独立的 API 实例内装入评测专用的文档仓储。实验仓储复用现有匹配条件和两轮查询顺序，只在原有候选统计与排序的位置计算 BM25。两组用同一评测身份调用同一试跑接口，沿用租户和数据源校验。

两组使用同一资料库快照、分词配置、向量模型、候选上限和父段落回填逻辑。主对照关闭可选的实体扩展和精排，逐题核对向量结果及其名次相同。向量失败降级或两组向量名次不一致的题需重跑，仍失败则进入报告的失败记录。中文结果只适用于本次实际使用的分词配置。

### 在同一资料范围计算 BM25

沿用入库时保存的分词结果和现有查询分词。先从同一租户及数据源的子段落快照统计词项出现的子段落数、每段长度和平均段落长度。长度按入索引的词项出现次数计。查询时仍按现有规则筛选候选，对全部匹配的段落计算 BM25，再取前 8 条进入合并。同分按段落编号排序。先用 `ts_rank` 截断再用 BM25 重排会遗漏本应由 BM25 找进前 8 条的段落。

首次对照采用 Apache Lucene 10.5.2 的 `BM25Similarity` 默认参数 `k1 = 1.2`、`b = 0.75` 和稀有词权重公式 `ln(1 + (N - df + 0.5) / (df + 0.5))`。`N` 是范围内的子段落总数，`df` 是包含该词的子段落数。频次和长度取已有分词结果。统计只在评测实例中随快照保存。相较原有排序，实验组多出统计准备和打分开销，复用现有存储和查询过滤条件，评测无需部署新的服务或迁移数据。

评测开始前和结束后用获准账号核对资料编号、更新时间、分块摘要和访问范围。试跑期间只读。资料或权限有变化时，废弃整次结果。先用带相同关键词的跨租户、跨数据源资料测试，确认范围外内容既无法进入结果，也不会改变已有候选的得分。

### 固定正式题集和判定条件

仓库已有的 16 道题用于跑通评测。正式题集用获准的业务资料及独立编写的问题，沿用「文档名 + 必含原文」标记标准证据。每道题指定一个主类别，至少各 20 道精确词、同义改写和多段证据题。精确词题中的牌号、标准编号和中文业务术语各至少 5 道，多段证据题覆盖同文档和跨文档情形。正式题目在运行前固定，调试使用另一组题。

复用 `retrieval_metrics.py`，按原文父段落计算前 5 条结果的证据覆盖率（Recall@5）和全部证据找齐率。报告保留逐题缺失的原文以及两组的关键词和合并名次。相同分词导致两组均找不到候选时，记录分词或匹配限制。

建议另立生产接入提案需同时满足以下条件。

- 精确词题的平均 Recall@5 至少提高 5 个百分点，以同题差值成对重采样得到的 95% 置信区间下限大于零。
- 整体、同义改写题和多段证据题的平均 Recall@5，以及多段证据题的全部证据找齐率，下降均小于 5 个百分点。
- 范围隔离检查通过，正式问题的两组结果完整，检索耗时符合预先登记的上限。

运行前登记语料规模、并发量和检索耗时上限。预热后交替两组执行顺序，报告从发出试跑请求到获得结果的 P50 和 P95 耗时，即 50% 和 95% 的请求可以在多长时间内完成。同时记录统计准备耗时、所用内存和超时次数。样本、耗时上限或必要结果缺失时，报告判为待验证。完整对照未达到改善、回归或耗时条件时，保留现有排序。

## Risks / Trade-offs

- 切词和匹配条件会限制两种算法能找到的候选。报告单独列出因切词或匹配遗漏而两组均未找到证据的题。
- 增加业务资料数量会增加统计准备时间和打分时间。报告写明实测规模，后续接入提案需用目标规模验证性能，并说明资料更新和删除后如何更新统计。
- 评测环境的实体扩展、精排、分词配置和线上使用情况可能不同。生产接入提案需要覆盖目标配置及启用这些能力时的回归验证。

## Migration Plan

评测通过现有接口把获准语料放入隔离环境，运行结束按该环境流程清理试验资料和统计。若实测通过，生产接入提案再明确实现方式、权限与统计更新、发布和回退步骤。
