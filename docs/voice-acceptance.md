# 语音真机验收跟念稿(Sakila)

> 执行人:________ 日期:________ 浏览器:________ 网络:________
> 账号:________ 租户/数据源:`sakila`
> 念 = 对着麦克风说;观察 = 看浮层文案、听声音、看页面结果。按编号顺序执行,不跳步。
> 浮层状态:连接中 / 聆听中,请说出你的问题 / 正在为您查询… / 正在播报,开口即可打断。
> 以下问题只针对 Sakila;已排除此前测过的影片总数与影片分类数量题。

## 0. 准备

- [ ] 登录后选择 `sakila` 租户/数据源。
- [ ] 允许浏览器使用麦克风;戴耳机,避免外放回声。
- [ ] 另开一个标签页打开 `chrome://webrtc-internals`,用于设备面检查。
- [ ] 点击通话入口,等浮层出现「聆听中,请说出你的问题」。

## 1. 基础补测(此前被打断/失败的两题)

### 1.1 演员数量

- 先念:**「一共有多少位演员?」**
- 观察:播报一个数量;页面结果表/图表与播报一致;从念完到「正在为您查询…」之间**没有**「我帮你查」类开场白;无中途卡住。

### 1.2 支付金额 Top 10 客户

- 等播报完全停止、浮层回到「聆听中,请说出你的问题」后,念:**「总支付金额最高的十位客户是谁?」**
- 观察:播报十位客户;姓名与页面结果一致;不截断、不编造。

## 2. 长句停顿防误切

### 2.1 按月、按门店的笔数与金额

- 念:**「按租赁月份统计每个门店的租赁笔数和总支付金额,按月份、门店排序。」**
- 念法:念到「租赁笔数」后停约 1 秒,再念「和总支付金额」;再停约 1 秒,念「按月份、门店排序」。正常换气,不要刻意连读。
- 观察:只发起一次查询;结果同时包含笔数与金额,按月份升序;不被切成两问、不重复查询。
- 说明:原句「按月」现在会先反问租赁月/支付月口径;这里用「租赁月份」测数据执行路径,不触发反问。

### 2.2 评级数量与两个均值

- 等播报完,念:**「不同电影评级分别有多少部影片,顺便算一下平均片长和平均租金。」**
- 念法:两个逗号后各停约 1 秒再继续。
- 观察:一次查询返回三类指标;评级标签(如 PG-13)原样播报;平均片长/租金与页面一致。

## 3. 多轮连续追问

### 3.1 租赁次数前五

- 等播报完全停止、浮层回到聆听中,念:**「租赁次数最多的前五部电影是哪几部?」**
- 观察:播报五部电影;结果表五条。
- 说明:若第 5 名处有多部并列(如 32 次),系统取满五行为正常;记录并列片名,不把并列省略判为数据错。

### 3.2 这五部的分类

- 等播报完全停止,念:**「这五部电影分别属于哪个分类?」**
- 观察:沿用上一轮「这五部」,不重新询问哪五部;分类与上一轮片名对应。

### 3.3 改为动作片前三

- 等播报完全停止,念:**「如果只统计动作片,排前三的是哪几部?」**
- 观察:在上一轮基础上改筛选条件;结果只含动作片,不混入上一轮的非动作片。
- 说明:3.2/3.3 依赖上一轮结果;关系桥/未知角色的归属误判已按结构规则修复。若仍失败,记录为多轮上下文问题,与语音链路分开,不拿失败结果当数据正确。

## 4. 停止意图与查询中途插话

### 4.1 等查询时只喊停

- 先念:**「列出每位客户在各门店的累计租赁次数和总消费金额。」**
- 页面出现「正在为您查询…」后,**立刻**念:**「先不查这个了。」**
- 观察:旧查询立即停止;听到「已停止」确认;页面不再推进旧查询;历史里出现已取消说明;输入框不回填旧问题。

### 4.2 停旧问、立刻问新题

- 等浮层回到聆听中,先念:**「按租赁月份统计每个门店的租赁笔数和总支付金额,按月份升序排列。」**
- 页面出现「正在为您查询…」后,**立刻**念:**「先不查这个了,告诉我参演电影最多的前三位演员是谁?」**
- 观察:旧轮取消、不继续推进;新问题正常作答;输入框不出现旧轮问题;两轮结果不串。

## 5. 零结果边界

### 5.1 超过 100 美元的订单

- 等播报完,念:**「单笔支付金额超过一百美元的订单一共有多少条?」**
- 观察:明确回答 0 条/没有;不编造数字;不把空结果说成有一条或若干条。

## 6. 打断与音色

### 6.1 播报中插话

- 先念:**「总支付金额最高的十位客户是谁?」**
- 等浮层进入「正在播报,开口即可打断」,在播报中途念:**「停一下。」**
- 观察:当前播报立即停止;没有两段声音叠在一起;回到聆听中;听到「已停止」确认。

### 6.2 无开场白、不叠音

- 任选 1.1 或 3.1 再问一次。
- 观察:提问后直接进入查询,不出现「我帮你查」类开场白;正式回答与停止确认音色一致(Serena);正式回答起播时本地确认音立即停止;无两种音色/两路声音同时出现。
