# ADR-010: AI 能力五大方向定调(通用为骨、数据为刃)

日期: 2026-10-09

状态: 已接受(owner 确认;开工载体:openspec 变更 088–091 与后续变更)

## 背景

Kongming 以问数智能体为首发王牌,三梯队落地后已具备完整执行底盘:ReAct 内核、
零凭证工具回调(ADR-002)、agent-memory、multi-model-routing、prompt-guardrails、
cloud-code-sandbox、可观测(038)。产品终局是通用多领域智能体平台(品牌定位
「全能 AI Agent 助手」),owner 于 2026-10-09 确认 AI 能力按五大方向组织:
**通用智能体、问答智能体、多智能体、问数智能体、评测智能体**。

## 决策

### 1. 五大方向是能力归口,不是五个系统

| 方向 | 定位 | 地基(已落地) | 缺口(开工载体) |
|---|---|---|---|
| 问数智能体 | 首发王牌、差异化刃口 | 一梯队 chat/nl2sql/nl2sql-agent 主链路 + 三梯队 semantic-layer / query-streaming / cloud-code-sandbox | 报告交付物闭环(088) |
| 问答智能体 | 知识问答 | rag 三路召回 / knowledge / document-rag / agent-memory / knowledge-qa | 知识侧深化(093-knowledge-qa 已落地归档) |
| 通用智能体 | 横向底盘、终局形态 | ReAct 内核 + 三梯队通用能力 | 工具广度(089 工具网关 + 后续工具域)+ 长任务内核(090) |
| 多智能体 | 复杂任务协作放大器 | workflow-orchestration(静态 DAG)/ custom-agent | 运行时动态协作(091,宿主 = 090) |
| 评测智能体 | 全方向质量闸门 | eval / ai-eval(Execution Match、基线、few-shot 自学习)+ agent-observability / eval-agent | 评测智能体化:LLM-as-judge、自动构造评测集(092-eval-agent 已落地归档) |

### 2. 通用为骨、数据为刃

通用能力(工具网关、任务内核、多智能体)是五大方向共用的骨架,优先做横向
复用度最高的部分;问数链路是差异化王牌,通用化的资源投放不得摊薄问数深度。
新工具域、新执行形态先服务问数场景验证,再开放为通用能力。

### 3. 一套底盘,不分叉

五大方向共用同一双进程底盘与信任边界(ADR-002)、同一工具回调、同一观测面
(038)、同一契约管线(ADR-005)、同一 schema 约定(ADR-004)。不为方向单独
立进程、单独立技术栈、单独建部署单元。

### 4. 立项纪律

新能力立项(proposal)须声明所属方向;跨方向能力按「宿主方向」归口(如
091 多智能体落地的协作编排同时服务通用与问数,宿主为通用)。未开工能力在
roadmap 第四梯队登记为待立项候选,开工再立 spec——既有「登记不背债」原则的
方向维延伸;本项目为个人学习与能力展示项目,登记面按能力展示清单维护,
不设「远期」时间档(owner 2026-10-10)。

## 否决项

- **按方向拆五个产品/五套部署**:方向是归口不是边界,拆分即重造跨进程税,
  且与 ADR-001「双进程双面」定案冲突。
- **为通用化牺牲问数深度**:摊大饼式横向扩张失去差异化,违反「数据为刃」。
- **放开宪法禁项换协作能力**:多智能体 worker 调度不引入消息队列(091 Non-goal,
  宪法 Article I 不变),协作用进程内编排 + DB 持久化语义承载。
- **评测独立成外部平台**:评测智能体内嵌于本平台(eval 域演进),服务其余
  四方向的持续质量,不做独立售卖的评测 SaaS。

## 与既有决策的关系

- **ADR-001/002**:五大方向全部落在既有双进程底盘上,信任边界零改动——
  089/090/091 三份提案均以此为设计硬约束。
- **宪法 Article IV(治理型网关)**:089 工具网关把 SQL 防火墙的治理模式推广
  为声明式工具域框架,是信任边界哲学的横向扩展而非边界移动。
- **roadmap 第四梯队**:五大方向的登记面与本 ADR 的决策面互为引用。

## 后果

- 正面:方向清晰,088–091 四份在库提案获得统一战略挂靠;后续新工具域/
  新能力按方向归类即可评估优先级;评测作为方向显式立项,质量闸门有归属。
- 负面:通用能力(任务内核、多智能体并发)token 成本放大——预算继承与
  失控防护(090/091 已内建上限硬约束)成为长期治理面;问答(093)与评测
  (092)两方向已落地归档(2026-10-10),能力展示清单五方向全部有落地载体。
