# Kongming 品牌基调

> 品牌 = 一个人 × 一个意象 × 一位军师。本文是品牌唯一事实源,
> 色彩/图形/文案的 token 定义以 `apps/web/src/index.css` 为准,两者冲突以本文意图为准。

## 一、品牌宇宙(三层意象合一)

| 层          | 来源         | 意象                                                 |
| ----------- | ------------ | ---------------------------------------------------- |
| **孔明**    | 项目名       | 智慧军师:运筹帷幄、算无遗策、羽扇轻摇                |
| **秋叶飞**  | 昵称(漆阳帆) | 秋阳下的飞叶:从容、灵动、沉淀之美                    |
| **Solvela** | 英文名       | Solve(解题)+ Vela(船帆座)——扬帆解题,亦呼应本名"阳帆" |

三者在本名中天然合一:**阳**帆 = 秋**阳**与扬**帆**;孔明是魂,秋叶是色,帆是形。

## 二、定位与口号

- **定位**:全能 AI Agent 助手——数据问答与分析(NL → SQL → 洞察)是首发王牌场景,
  工具调用/工作流/沙箱分析逐步长出全能形态。
- **主口号**:**万事,问孔明。**(全能助手定位,四字一顿,古韵克制)
- **副口号**:秋叶飞时,运筹帷幄。(品牌气氛句,用于登录页/空状态等"秋叶时刻")
- **英文署名**:Solvela · Solve with sail.

## 三、色彩体系(武侯祠三元:红墙 · 黛瓦 · 鎏金)

色彩定稿历经三轮:**秋叶橙黄**(大面积高唤醒刺眼,弃)→ **墨青为体秋金为睛**
(方向正确)→ 终稿**武侯祠三元色**——取成都武侯祠的标志性画面
「红墙黛瓦、鎏金匾额、翠竹掩映」,对位品牌角色:

| 色彩                 | 来源意象           | 品牌角色                                 |
| -------------------- | ------------------ | ---------------------------------------- |
| **朱砂红** `#8f2d2f` | 红墙 / 朱批        | primary:决断与庄重(孔明之谋,落笔即定)    |
| **黛青**             | 黛瓦 / 纶巾 / 青石 | 大面积与背景:运筹帷幄的沉静              |
| **鎏金** `#c9a063`   | 匾额之金 / 秋叶    | 点睛:焦点环、logo 一笔,惜色如金,禁大面积 |

羽扇纶巾的儒雅 = 黛青打底;运筹帷幄的掌控感 = 朱砂落点;匾额鎏金 = 名垂宇宙的一点亮。

### Token 表(`index.css` 为准)

| Token                                  | 亮色值                                               | 暗色值              | 语义                            |
| -------------------------------------- | ---------------------------------------------------- | ------------------- | ------------------------------- |
| `--primary`                            | `#8f2d2f`(红墙朱砂)                                  | `#b0484a`(夜祠朱门) | 主操作、链接、强调              |
| `--accent`                             | `#f5edda`(宣纸米黄)                                  | `#2a2018`(暗金底)   | 选中态、hover 底色              |
| `--ring`                               | `#c9a063`(鎏金)                                      | `#c9a063`           | **点睛**:匾额之金,哑光不炫      |
| `gild`                                 | `#c9a063`                                            | 同                  | 鎏金点缀(logo/高亮,禁大面积)    |
| `--background`                         | `#fbfaf7`(宣纸白)                                    | `#0e1416`(黛墨夜)   | 页面底色                        |
| 渐变 `grad-from → grad-mid → grad-end` | `#2e4a56 → #1d3742 → #0f1a22`(黛瓦暮色:黛→深黛→青墨) | 同                  | 品牌渐变,登录页等"运筹时刻"专用 |

浮层 token(shadcn 语义补齐,006):`--popover/--popover-foreground` 为
card 同族别名(浮层=卡片形态),不引入新色相。
无障碍说明:亮色 `--primary` 深朱,宣纸白前景对比 ≥ 7:1;错误语义用鲜红
`#dc2626`,与朱砂 primary 靠明度/饱和差异区分;中性色为青灰系(配黛瓦)。
禁再引入第四主色;鎏金只许以 ring/点缀/小面积出现。

## 四、图形母题

**一片"羽扇形的帆"**(Logo 方向,待设计落地):叶脉即扇骨,叶形即帆面——
一笔图形同时是秋叶(品牌色来源)、羽扇(孔明)、船帆(Solvela)。
简化线条风格,单色描边可反白;在 loading/空状态可做"落叶飘下"的克制动效。

## 五、文案调性

像一位冷静的军师说话:**短句、笃定、有古韵、不堆形容词**。

- ✅「问计于数据,如问计于孔明」「此事,已有对策」「秋叶落,结果出」
- ❌「超强的 AI 智能引擎,赋能企业数据价值腾飞」
- 错误文案给"对策"而非道歉:「该问涉及写操作,已按军规拦下」
- 注释/文档保持简体中文;产品文案禁止 emoji 与感叹号堆叠。

## 七、变更纪律

品牌 token 的任何调整视为设计决策变更:改 `index.css` 前先改本文(记录意图),
保持"文档定意、CSS 定值"的单源关系;渐变/主色不得在组件内散落出现(前端样式铁律 3/6/7)。
